# Interpretable Membership Inference in Diffusion Models

This project presents an Explainable AI (XAI) framework for identifying whether a given image was part of a diffusion model’s training set. Our approach provides both intrinsic (latent space) and extrinsic (output space) analyses to evaluate training data attribution without requiring access to the original dataset.
